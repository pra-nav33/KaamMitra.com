# KaamMitra.com

### A Service Marketplace Platform Connecting Customers with Trusted Local Workers

KaamMitra.com is a web-based service marketplace designed to connect customers with local service providers such as plumbers, electricians, household workers, IT technicians, and other skilled professionals.

The platform provides separate interfaces for **Customers, Workers, and Administrators**, making it easier to discover services, request workers, manage bookings, communicate, and manage the overall platform.

---

## Project Overview

Finding a reliable worker for everyday services can often be difficult. KaamMitra.com aims to provide a centralized platform where customers can find suitable workers based on their service requirements and location.

Workers can create and manage their profiles, receive service requests, manage jobs, and track their earnings.

Administrators can manage users, workers, services, bookings, payments, complaints, and platform settings.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/pra-nav33/KaamMitra.com.git
```

### 2. Open the project

```bash
cd KaamMitra.com
```

### 3. Open the frontend

Open the project in Visual Studio Code.

Navigate to:

```text
frontend/index.html
```

### 4. Run with Live Server

Right-click `index.html` and select:

**Open with Live Server**

The KaamMitra.com frontend will open in your browser.
